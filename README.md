This project is a randomizer for the videogame "Pizza Connection 2" or for non-europeans "Fast Food Tycoon 2".
Unfortunately I decided to use Windows Forms for this project. It is not yet finished and may contain bugs.

This project uses a library to alter RAM for other processes (namely fastfood2.exe or pc2.exe). Use everything here at your own risk!
The memory library used can be found here: https://github.com/erfg12/memory.dll
